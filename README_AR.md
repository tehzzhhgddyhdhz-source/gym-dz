# Gym DZ — النسخة التجريبية

موقع رياضي باللغة العربية والدارجة الجزائرية، بتصميم أسود وبرتقالي. يحتوي على:
- أقسام أهداف التدريب (بناء العضلات، التنشيف، التغذية).
- قائمة تمارين قابلة للتصفية حسب العضلة.
- حاسبة تقديرية للبروتين.
- برنامج أسبوعي تجريبي ونصيحة يومية.
- إعدادات PWA أولية للتثبيت على أندرويد والعمل دون اتصال بعد أول تحميل.

## تشغيله محليًا
افتح `index.html` في المتصفح لمعاينة معظم المزايا. تثبيت PWA وخدمة العمل دون اتصال يحتاجان إلى استضافة HTTPS أو `localhost`.

## نشر مجاني عبر GitHub Pages
1. أنشئ حسابًا في GitHub.
2. أنشئ مستودعًا جديدًا باسم `gym-dz` واجعله Public.
3. ارفع جميع الملفات الموجودة في هذا المجلد إلى جذر المستودع.
4. افتح Settings ثم Pages.
5. اختر `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)` واحفظ.
6. انتظر حتى يظهر رابط الموقع في صفحة Pages.
7. افتح الرابط في Chrome على هاتف أندرويد. من قائمة Chrome اختر `Install app` أو `Add to Home screen` إذا ظهر الخيار.

## ملاحظات مهمة
- هذه نسخة أولية ثابتة؛ لا يوجد فيها حسابات مستخدمين أو قاعدة بيانات أو إدارة طلبات/محتوى عن بُعد.
- حاسبة البروتين تقديرية للتثقيف العام وليست نصيحة طبية.
- لا ترفع بيانات شخصية حساسة إلى نسخة عامة.
- Google Play ليس ضروريًا لتجربة تطبيق الويب، لكنه يتطلب إجراءات ورسومًا مستقلة إذا أردت النشر كحزمة أندرويد.
